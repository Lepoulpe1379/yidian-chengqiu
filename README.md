# 一点成球

一个点同时做径向往复、绕竖直轴旋转和倾角进动。同一条轨迹投影到 x 轴是线段，投影到 xz 平面是圆盘，完整透视才像一个球。看起来像实体，是轨迹残留造成的视觉暂留，点本身没有变成球体。

演示是单个 HTML 文件，用 Canvas 绘制，不依赖构建工具或第三方库。

## 打开方式

用浏览器直接打开 [`point-to-sphere.html`](point-to-sphere.html)。

也可以在本目录起一个本地静态服务后访问：

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080/point-to-sphere.html`。种子保存在浏览器 `localStorage` 里，换端口或换浏览器后记录互不相通。

## 画面

| 视图 | 内容 |
| --- | --- |
| 一维 | 只保留 x，点在一条线段上往复 |
| 二维 | 保留 x 与 z，轨迹扫成圆盘 |
| 三维 | 透视投影，轨迹逐渐填满球面附近 |

拖拽三维画面可以旋转视角。

## 运动

位置按球坐标计算：

```text
r = R · |sin(ω_r t)|
θ = π/2 + 0.92 · sin(ω_θ t)
φ = ω_φ t

x = r · sin(θ) · cos(φ)
y = r · cos(θ)
z = r · sin(θ) · sin(φ)
```

`ω_r`、`ω_φ`、`ω_θ` 尽量不要成简单整数比，扫过的区域更均匀。

## 操作

右侧数值都可以双击后直接输入。

| 控件 | 范围 | 说明 |
| --- | --- | --- |
| 总速度倍率 | 0.05× – 10 万× | 对数滑块，整体加快或放慢时间 |
| 径向往复 ω_r | 0.2 – 12 | 点在半径方向来回 |
| 绕轴旋转 ω_φ | 0.2 – 12 | 绕竖直轴转动 |
| 倾角进动 ω_θ | 0.2 – 12 | 改变极角，让轨迹离开赤道 |
| 轨迹残留长度 | 100 – 1 亿 | 对数滑块，只保留最近这么多个点 |
| 球体半径 | 0.4 – 1.4 | 步进 0.05 |
| 显示当前点 | 开关 | 是否画出正在运动的那个点 |
| 暂停 / 继续 | — | 停止或恢复积分 |
| 清空轨迹 | — | 丢掉已记录的点 |
| 一键：接近填满球 | — | 切到一组扫得比较满的参数，并清空旧轨迹 |

点数很多时，画面最多均匀抽取约 5000 个点来画，右上角计数仍是实际保留的点数。

## 种子

当前参数（三个角速度、速度、轨迹长度、半径、是否显示当前点、三维视角）可以存成种子。

- **保存种子**：写入本机 `localStorage`（键名 `point-to-sphere-seeds`）。勾选「同时导出」会下载一份 JSON。
- **加载种子**：从本地历史里选一条应用。应用后会清空当前轨迹。
- **导入**：读取导出的 JSON，按名称合并进本地历史。同名会覆盖。只导入一条时会立刻加载。
- **删除**：从本地历史里去掉选中的种子。

导出文件形如：

```json
{
  "version": 1,
  "seeds": [
    {
      "name": "接近填满",
      "savedAt": "2026-10-14T00:00:00.000Z",
      "params": {
        "speed": 2.5,
        "wr": 5.3,
        "wphi": 8.7,
        "wtheta": 3.1,
        "trail": 3500,
        "radius": 1,
        "showPoint": true,
        "rotX": 0.35,
        "rotY": -0.55
      }
    }
  ]
}
```
